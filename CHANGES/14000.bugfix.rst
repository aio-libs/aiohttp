Fixed a crash in :class:`~aiohttp.web.RequestHandler` when a connection is
lost while the handler is parked waiting for the next keep-alive request.
Previously this raised ``TypeError: 'NoneType' object is not callable``
because :meth:`~aiohttp.web.RequestHandler.start` called the request factory
after :meth:`~aiohttp.web.RequestHandler.connection_lost` had cleared it
-- by :user:`inchang-ing`.
