Fixed the client framing a request body as chunked without sending
``Transfer-Encoding: chunked``: ``chunked=False`` chunk-encoded the body behind
a ``Content-Length`` header, and a ``GET``, ``HEAD``, ``OPTIONS`` or ``TRACE``
request without a body sent a stray ``0\r\n\r\n`` terminator when ``chunked``
was set (for example, the ``GET`` following a ``303`` redirect of a
``chunked=True`` ``POST``), which servers rejected with ``400 Bad Request``
-- by :user:`HelmiDev03`.
